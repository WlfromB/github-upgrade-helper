🚀 github-upgrade-helper

Деплой репозиториев на этот сервер без GitHub Actions: fetch → checkout → docker compose → health-check. Один запуск за раз, логи ниже.
📖 Как пользоваться (инструкция)

1. Первый запуск на сервере

Нужны Python 3.9+, git, docker compose и клоны репозиториев (для проекта WlfromB они уже в /opt/*).

git clone https://github.com/WlfromB/github-upgrade-helper.git /opt/github-upgrade-helper
cd /opt/github-upgrade-helper && python3 server.py

Откроется http://127.0.0.1:8790 (или SSH-туннель: ssh -L 8790:127.0.0.1:8790 root@сервер). Для автозапуска — systemd: sudo cp deploy/github-upgrade-helper.service /etc/systemd/system/ && sudo systemctl enable --now github-upgrade-helper.

2. Приватные репозитории — токен

Создайте Personal Access Token: GitHub → Settings → Developer settings → Personal access tokens → classic, галочка repo. Вставьте токен в поле «Токен» при добавлении репозитория (или один раз в config.json → settings.githubToken). Токен нужен только если у сервера нет SSH-ключа с доступом к репозиторию.

3. Добавление репозитория

Вставьте ссылку в любом виде — https://github.com/WlfromB/fitness-frontend, git@github.com:… или просто owner/name. Если клона ещё нет — он создастся в settings.workspaceRoot (по умолчанию /opt). Для известных репозиториев WlfromB compose-сервис и health-проверка подставятся сами.

4. Деплой

У карточки репозитория введите ветку/тег/SHA (по умолчанию — main) и нажмите «Деплой». Что произойдёт: git fetch → checkout → docker compose build SERVICE → up -d --force-recreate → health-check. Галочка «dry-run» — только обновить исходники и показать коммит, контейнеры не трогать (безопасно для проверки).

5. Откат

Отката «кнопкой назад» нет намеренно: просто запустите деплой снова с прежним ref (тегом/коммитом/веткой). Пример: катили feature/x — вернитесь деплоем main. История запусков (с ref и коммитом) — в разделе «Запуски».

6. Безопасность

Приложение выполняет команды git/docker на сервере, поэтому: по умолчанию слушает только 127.0.0.1 (снаружи не видно); задайте пароль в config.json → settings.password, если открываете наружу; не открывайте порт без HTTPS/VPN. Токены хранятся в config.json на сервере и не показываются в UI.
